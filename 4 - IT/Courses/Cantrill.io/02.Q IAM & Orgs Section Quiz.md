
1. ***What Permissions options does an AMI have?***
	E.
		In AWS, an **Amazon Machine Image (AMI)** controls who can use it to launch EC2 instances through its **launch permissions**. There are ==three main permissions options available==:
		 **Private:** By default, an AMI is private and its launch permissions belong only to the owner's AWS account.
		  **Explicit:** You explicitly grant launch permissions to specific AWS account numbers or AWS Organizations/Organizational Units (OUs).
		  - **Public:** You grant launch permission to all AWS account holders, making the AMI globally discoverable and deployable

12. ***Who manages the DNS Root Servers?***
	E.

19. ***What is the IP CIDR of a default VPC?***
	E.
		 #DNSRECORDTYPE
		in Amazon Web Services (AWS), the default Virtual Private Cloud (VPC) in every region is assigned the ==IPv4 CIDR block== **`172.31.0.0/16
			This CIDR block provides the following: 
			- Total IP Addresses:** 65,536 (ranging from `172.31.0.0` to `172.31.255.255`)
			- **Default Subnets:** Automatically created in each Availability Zone (AZ) with a **`/20`** CIDR block
			- **Subnet IPs:** 4,096 IP addresses per default subnet (with a few reserved by AWS for internal networking.
