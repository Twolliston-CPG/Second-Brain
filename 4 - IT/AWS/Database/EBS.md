**Amazon EBS (Elastic Block Store)** gives an EC2 instance a persistent virtual hard drive. Without it, data on an instance's local storage disappears when the instance stops. An EBS volume behaves like a raw disk: you format it, install an operating system or database on it, and get low-latency reads and writes. It survives instance restarts, can be snapshotted for backup, and comes in SSD and HDD types tuned for performance or cost. The main limitation is that a volume lives in one Availability Zone and is generally attached to one instance at a time. Typical uses are boot volumes, relational databases, and any single-server workload that needs fast disk.
