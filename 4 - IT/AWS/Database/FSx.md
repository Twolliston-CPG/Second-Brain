**Amazon FSx** handles cases where a generic file system isn't enough and you need a specific, fully featured one, managed for you. FSx for Windows File Server gives you native SMB shares with Active Directory integration and Windows permissions, which helps when moving Windows apps, file shares, or SQL Server to AWS. FSx for Lustre is a high-performance parallel file system for workloads like machine learning training, HPC, genomics, and video rendering, and it can link directly to an S3 bucket. There are also FSx variants for NetApp ONTAP and OpenZFS for teams migrating those environments.
