**Amazon ElastiCache (Redis/Memcached)** solves the speed and load problem. It keeps frequently used data in memory, so reads come back in microseconds instead of hitting your main database every time. This cuts latency and protects the backend database from being overwhelmed. Common uses are caching query results, session storage, real-time counters, and leaderboards. Redis adds richer data structures and persistence options; Memcached is simpler, pure caching.
