**Amazon S3 (Simple Storage Service)** solves the problem of storing a practically unlimited amount of data cheaply and durably, without managing servers or disks. You put files ("objects") into **buckets** and get them back through an API or URL, from anywhere. AWS stores multiple copies across facilities and advertises 11 nines of durability. **Storage classes** let you pay less for data you access less often. S3 Standard is for hot data, Standard-IA and One Zone-IA are for infrequently accessed data, and Intelligent-Tiering moves objects between tiers automatically when access patterns are unpredictable. **Lifecycle policies** automate cost management, for example "move logs to IA after 30 days, to Glacier after 90, delete after 1 year." Typical uses are backups, data lakes, static website assets, media files, and application uploads. The trade-off is that S3 isn't a disk: you can't mount it and edit a file in place the way an operating system expects
