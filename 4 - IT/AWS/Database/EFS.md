**Amazon EFS (Elastic File System)** solves the problem of many servers needing the same files at the same time. It's a managed NFS file system that many EC2 instances, containers, or Lambda functions can mount at once, across Availability Zones. It grows and shrinks automatically, so you never provision capacity. Typical uses are shared web content, content management systems, home directories, and container workloads that need shared persistent storage. It's Linux-oriented and costs more per GB than S3
