A quick way to choose:

|Need|Service|
|---|---|
|Store files/objects at scale, access via API|S3|
|A fast disk for one EC2 instance (OS, database)|EBS|
|A shared Linux file system for many servers|EFS|
|Windows file shares or high-performance computing|FSx|
|Cheap long-term archive, rarely accessed|S3 Glacier / Deep Archive|
