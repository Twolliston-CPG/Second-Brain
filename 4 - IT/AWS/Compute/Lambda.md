**AWS Lambda**  
The problem: even with EC2, you pay for servers sitting idle and you still have to patch, scale, and keep them alive. Lambda lets you upload a function that runs only when something triggers it, such as an HTTP request, a file upload to S3, a queue message, or a schedule. AWS handles all the servers and scaling (from zero up to thousands of concurrent runs), and you pay only for the milliseconds your code executes. It works well for event-driven tasks, APIs with spiky traffic, and glue code between services. The limits are a 15-minute maximum run time, cold-start latency, and less control over the environment.
