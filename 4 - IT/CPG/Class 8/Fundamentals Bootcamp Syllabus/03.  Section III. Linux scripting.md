#Linux_Scripting

This section moves students from issuing individual Linux commands toward combining
those commands into reusable Bash scripts. Students will learn how scripts allow
repetitive terminal operations to be documented, automated, and executed consistently.
The section also introduces permissions, executable files, shell variables, basic script
structure, and terminal-based editing with Vim. Bash scripting remains widely used in
systems administration, cloud environments, CI/CD pipelines, server initialization,
developer tooling, and operational automation.

## **Class lab:**
• ***Create a Bash script:*** Write a small .sh script that declares variables and executes
several Linux commands as a repeatable workflow.

• ***Execute and troubleshoot scripts:*** Add execute permissions with chmod, run the
script from the terminal, and inspect basic errors caused by paths, permissions, or
incorrect commands.

• ***Vim fundamentals:*** Open and modify a file using Vim while practicing command
mode, insert mode, saving, and exiting. Students will discuss why terminal editors
remain useful when working with remote Linux servers and cloud systems.
