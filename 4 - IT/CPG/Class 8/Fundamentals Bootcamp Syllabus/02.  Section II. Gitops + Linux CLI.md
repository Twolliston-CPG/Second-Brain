#Gitops_Linux_cli 

This section introduces the Linux command line alongside the basic Git and GitHub
workflow commonly used by software development teams. Students will learn to navigate
and manipulate files without relying exclusively on a graphical interface while also learning
how source code is tracked through version control. They will practice the relationship
between a local Git repository and its remote GitHub counterpart, including branches,
commits, pushes, and pull requests. In the workplace, these skills underpin collaborative
development, code review, infrastructure management, deployment pipelines, and nearly
every modern DevOps workflow.

## **Class lab:**
• Linux CLI navigation: Use commands such as pwd, ls, cd, mkdir, touch, cp, mv, cat,
and rm to navigate and manipulate a project directory from the terminal.

•  Local and remote Git repositories: Initialize a local Git repository, create a GitHub
repository, configure the remote connection, and push locally committed files to
GitHub.

• Branch and pull request workflow: Create a feature branch, modify project files,
commit and push the branch, and submit a pull request. Students will see how this
process supports team collaboration and controlled changes to shared codebases.

## **Useful commands:**

**git commit -m "Add Python Script"**
**git push**

*If you get this error after **git push***
"`fatal: The current branch python-script has no upstream branch.`
`To push the current branch and set the remote as upstream, use`

    git push --set-upstream origin python-script
"
*You get this error because Github doesn't know about the branch you created on your local machine*

run this command 
git push --set-upstream origin python-script
