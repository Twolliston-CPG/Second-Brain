#Section_I_IDE_and_File_Management

Dates: Monday, September 21st – Friday, September 25 (Daily)

Time: 07:30p EST – 9p EST

This section introduces students to the development environment they will use throughout
the course and establishes foundational computer file-management concepts. Students
will configure the required software, become familiar with Visual Studio Code, and learn
how files and directories are represented and organized on their local machine. Particular
attention will be given to absolute and relative file paths, file extensions, directory
structures, and navigating a software project from an IDE. These concepts directly reflect
workplace expectations, where developers routinely move between project folders,
configuration files, source code, terminals, and repositories.

## ***Class lab:***

-  Development environment setup: Install and verify required software, including
Visual Studio Code, Git, Python, and the terminal environment. Students will
confirm that each tool can be launched and accessed successfully.

- File and directory navigation: Create a simple project directory and practice
opening, creating, renaming, moving, and deleting files using both the operating
system and Visual Studio Code.

- Hello World HTML exercise: Create a basic HTML document in VS Code and open it
in a browser. Students will use this exercise to connect source files, file extensions,
directory paths, and application execution.
