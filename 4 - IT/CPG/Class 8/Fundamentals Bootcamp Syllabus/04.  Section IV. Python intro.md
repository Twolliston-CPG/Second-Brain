#Python_Intro

This section introduces Python as the course's first general-purpose programming
language. Students will learn how Python represents data using variables, makes decisions
with conditional statements, and organizes reusable behavior through functions. The
emphasis will be on understanding program execution and learning to read simple code
rather than memorizing large amounts of syntax. These same concepts form the
foundation of Python applications used for automation, data engineering, cloud
administration, APIs, testing, and backend development.

## **Class lab:**
**Variables and data:** Create variables containing strings, numbers, and Boolean values, then
print and modify those values during program execution.

**Conditional logic:** Use if, elif, and else statements to change program behavior based on
variable values and user input.

**Functions:** Define and call a simple Python function that accepts information, performs an
operation, and returns or displays a result. Students will connect functions to the reusable
application logic found in production software.
