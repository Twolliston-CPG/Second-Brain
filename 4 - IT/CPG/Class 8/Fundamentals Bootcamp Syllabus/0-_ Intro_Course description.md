#Intro_Course_description

Dates: Monday, September 21st – Friday, September 25 (Daily)

Time: 07:30p EST – 9p EST

Description: This introductory course provides students with the foundational tools and
workflows used in modern software development, cloud engineering, DevOps, and IT
operations. Over five sessions, students will progress from configuring a local development
environment to working with Linux, GitHub, Bash, Python, and basic automation concepts.
The course emphasizes hands-on practice rather than isolated theory, with each section
building on skills introduced during the previous session. Students will learn not only how
individual tools work, but also how those tools interact within a typical development
workflow. By the end of the course, students will combine Linux commands, scripts,
Python code, and file management into a small orchestration workflow similar to those
used in real technical environments.
