### ** Use commands **

**aws sts get-caller-identity**
  *The aws sts get-caller-identity command is used in the AWS CLI to retrieve details about the IAM identity (user, role, or federated entity) currently being used to authenticate your AWS requests. It is essentially the AWS equivalent of the whoami command in Linux*
